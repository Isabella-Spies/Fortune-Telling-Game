# Character Tracker Project
## An organizational tool to gather characters from across time, space, and Google Docs.

The project that I intend to design this term is a character tracker designed for Dungeon's and Dragons. With this tool, users will be able to make a game and then add participating characters to this game. Additionally, characters can be edited to include important information such as: 
- Name
- age
- appearance
- statistics

The D&D Character Tracker is designed for game masters, players, or even writers. With the intention of creating a centralized place to store, edit, organize, and quickly access their character information. This project is of interest to me because I play in many custom games that pre-existing software options, such as D&D Beyond, do not accommodate. I am in need of a simple, yet organized way to store character sheet data that isn't a google doc, google sheet, or piece of paper. 


## User Stories
Below are user stories. These will be continually updated as the project progresses.

- I want to be able to add a character to my list of characters.
- I want to be able to view a list of every character
- I want to be able to create a character and specify information such as, name, age, appearance description, game, and ability scores.
- I want to be able to select a character and view a list of their information.
- I want to be able to select a character and edit their information. 
- I want to be able to select and remove a character from a game.
