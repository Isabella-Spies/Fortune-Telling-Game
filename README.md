# Fortune Telling Game
## A game for those in need of quick (not necessarily accurate) divination

The project that I intend to design this term is a fortune telling game. Users will be able to make a fortune and then add it to a fortune log. The player will add a topic and then choose between two types of fortunes: 
- Coin Flip
- Card Reading

This project is designed to be a fun little game for those who like fortune telling. It is of interest to me as I really enjoy fortune telling and game design.  


## User stories: 
- I want to be able to make a game and add it to a list of previous games
- I want to be able to specify a topic for the fortune and choose between a coin flip or card reading and receive a result fortune
- I want to be able to select a fortune and rate it
- I want to be able to see a list of fortunes with a good rating
- I want to be able to see a list of fortunes with a bad rating
- I want to be able to see a list of all fortunes and their results.
